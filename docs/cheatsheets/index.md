# Accusative Cheatsheets

Quick visual references for all Accusative patterns.

---

## The Golden Rule

| Type | Change |
|:-----|:-------|
| **Masc. Animate** | -a (hard) or -e (soft) |
| **Masc. Inanimate** | NO CHANGE |
| **Feminine -a** | -u |
| **Feminine -e** | -i |
| **Neuter** | NO CHANGE |

## Quick Reference

### Singular

| Gender | Nominative | Accusative |
|:-------|:-----------|:-----------|
| Masc. Animate Hard | student | student**a** |
| Masc. Animate Soft | muž | muž**e** |
| Masc. Inanimate | stůl | stůl |
| Feminine -a | žena | žen**u** |
| Feminine -e | růže | růž**i** |
| Neuter | město | město |

### Plural

| Gender | Nom. Plural | Acc. Plural |
|:-------|:------------|:------------|
| Masc. Animate Hard | studenti | student**y** |
| Masc. Animate Soft | muži | muž**e** |
| Everything else | (same as nominative) | (same) |
