# Direct Object Practice

The most common use of accusative - after verbs!

---

## Verbs with Mít (to have)

Complete with the accusative form:

1. Mám ___ (bratr) → I have a brother.
2. Mám ___ (sestra) → I have a sister.
3. Mám ___ (auto) → I have a car.
4. Mám ___ (pes) → I have a dog.
5. Mám ___ (kočka) → I have a cat.
6. Mám ___ (problém) → I have a problem.
7. Mám ___ (nápad) → I have an idea.
8. Mám ___ (čas) → I have time.
9. Mám ___ (práce) → I have work.
10. Mám ___ (otázka) → I have a question.

<details>
<summary>**Answers**</summary>

1. Mám **bratra** (masc. animate → -a)
2. Mám **sestru** (fem. -a → -u)
3. Mám **auto** (neuter → no change)
4. Mám **psa** (masc. animate → -a)
5. Mám **kočku** (fem. -a → -u)
6. Mám **problém** (masc. inanimate → no change)
7. Mám **nápad** (masc. inanimate → no change)
8. Mám **čas** (masc. inanimate → no change)
9. Mám **práci** (fem. -e → -i)
10. Mám **otázku** (fem. -a → -u)

</details>

## Verbs with Vidět (to see)

1. Vidím ___ (student) → I see a student.
2. Vidím ___ (učitel) → I see a teacher.
3. Vidím ___ (žena) → I see a woman.
4. Vidím ___ (dítě) → I see a child.
5. Vidím ___ (hrad) → I see a castle.
6. Vidím ___ (hora) → I see a mountain.
7. Vidím ___ (moře) → I see the sea.
8. Vidím ___ (přítel) → I see a friend.

<details>
<summary>**Answers**</summary>

1. Vidím **studenta** (masc. animate hard → -a)
2. Vidím **učitele** (masc. animate soft → -e)
3. Vidím **ženu** (fem. -a → -u)
4. Vidím **dítě** (neuter → no change)
5. Vidím **hrad** (masc. inanimate → no change)
6. Vidím **horu** (fem. -a → -u)
7. Vidím **moře** (neuter → no change)
8. Vidím **přítele** (masc. animate soft → -e)

</details>

## Verbs with Znát (to know)

1. Znám ___ (Praha) → I know Prague.
2. Znám ___ (Petr) → I know Petr.
3. Znám ___ (Marie) → I know Marie.
4. Znám ___ (ten film) → I know that film.
5. Znám ___ (ta píseň) → I know that song.
6. Znám ___ (ten muž) → I know that man.
7. Znám ___ (ta žena) → I know that woman.
8. Znám ___ (Česká republika) → I know the Czech Republic.

<details>
<summary>**Answers**</summary>

1. Znám **Prahu** (fem. -a → -u)
2. Znám **Petra** (masc. animate → -a)
3. Znám **Marii** (fem. -e → -i)
4. Znám **ten film** (masc. inanimate → no change)
5. Znám **tu píseň** (fem. consonant → no change, demonstrative ta→tu)
6. Znám **toho muže** (masc. animate, demonstrative ten→toho)
7. Znám **tu ženu** (fem., demonstrative ta→tu)
8. Znám **Českou republiku** (fem. + adj. → -ou, -u)

</details>

## Verbs with Chtít (to want)

1. Chci ___ (káva) → I want coffee.
2. Chci ___ (čaj) → I want tea.
3. Chci ___ (pivo) → I want beer.
4. Chci ___ (voda) → I want water.
5. Chci ___ (jablko) → I want an apple.
6. Chci ___ (nový telefon) → I want a new phone.
7. Chci ___ (malá káva) → I want a small coffee.
8. Chci ___ (velké pivo) → I want a big beer.

<details>
<summary>**Answers**</summary>

1. Chci **kávu** (fem. -a → -u)
2. Chci **čaj** (masc. inanimate → no change)
3. Chci **pivo** (neuter → no change)
4. Chci **vodu** (fem. -a → -u)
5. Chci **jablko** (neuter → no change)
6. Chci **nový telefon** (masc. inanimate → no change)
7. Chci **malou kávu** (fem. adj. -á → -ou, noun -a → -u)
8. Chci **velké pivo** (neuter → no change)

</details>

## Mixed Practice

Use the correct verb and accusative form:

1. ___ (číst) ___ (kniha) → I read a book.
2. ___ (psát) ___ (dopis) → I write a letter.
3. ___ (jíst) ___ (oběd) → I eat lunch.
4. ___ (pít) ___ (voda) → I drink water.
5. ___ (milovat) ___ (ty) → I love you.
6. ___ (potřebovat) ___ (pomoc) → I need help.
7. ___ (kupovat) ___ (dárek) → I buy a gift.
8. ___ (hledat) ___ (práce) → I'm looking for work.

<details>
<summary>**Answers**</summary>

1. **Čtu knihu.** (kniha → knihu)
2. **Píšu dopis.** (dopis → dopis, no change)
3. **Jím oběd.** (oběd → oběd, no change)
4. **Piju vodu.** (voda → vodu)
5. **Miluju tě.** (ty → tě)
6. **Potřebuji pomoc.** (pomoc → pomoc, no change)
7. **Kupuji dárek.** (dárek → dárek, no change)
8. **Hledám práci.** (práce → práci)

</details>

## Plural Direct Objects

1. Vidím ___ (studenti) → I see students.
2. Mám ___ (knihy) → I have books.
3. Znám ___ (ty lidé) → I know those people.
4. Vidím ___ (psi) → I see dogs.
5. Čtu ___ (noviny) → I read newspapers.

<details>
<summary>**Answers**</summary>

1. Vidím **studenty** (masc. animate pl. → -y)
2. Mám **knihy** (fem. pl. → no change)
3. Znám **ty lidi** (masc. animate pl. → irregular)
4. Vidím **psy** (masc. animate pl. → -y)
5. Čtu **noviny** (fem. pl. → no change)

</details>
