## Quick Practice: Dative Verbs

Put the noun in Dative:

### Set 1: Pomáhat (to help)

1. Pomáhám ___ (bratr) →
2. Pomáhám ___ (sestra) →
3. Pomáhám ___ (matka) →
4. Pomáhám ___ (učitel) →
5. Pomáhám ___ (kamarádka) →

<details>
<summary>**Answers**</summary>

1. Pomáhám **bratrovi** (masc. animate → -ovi)
2. Pomáhám **sestře** (fem. -a, r→ř → -e)
3. Pomáhám **matce** (fem. -a, k→c → -e)
4. Pomáhám **učitelovi** (masc. animate → -ovi)
5. Pomáhám **kamarádce** (fem. -a, k→c → -e)

</details>

### Set 2: Věřit (to believe)

1. Věřím ___ (on) →
2. Věřím ___ (ona) →
3. Věřím ___ (ty) →
4. Věřím ___ (doktor) →
5. Věřím ___ (přítel) →

<details>
<summary>**Answers**</summary>

1. Věřím **mu** (pronoun)
2. Věřím **jí** (pronoun)
3. Věřím **ti** (pronoun)
4. Věřím **doktorovi** (masc. animate → -ovi)
5. Věřím **příteli** / **přítelovi** (masc. animate soft)

</details>

### Set 3: With Preposition K

1. Jdu k ___ (doktor) →
2. Jdu k ___ (město) →
3. Jdu k ___ (hrad) →
4. Jdu k ___ (Praha) →
5. Jdu k ___ (moře) →

<details>
<summary>**Answers**</summary>

1. Jdu k **doktorovi** (masc. animate → -ovi)
2. Jdu k **městu** (neuter -o → -u)
3. Jdu k **hradu** (masc. inanimate → -u)
4. Jdu k **Praze** (fem. -a, h→z → -e)
5. Jdu k **moři** (neuter -e → -i)

</details>

## Transformation Drill

Transform from Nominative to Dative:

| Nominative | → Dative |
|:-----------|:---------|
| bratr | ? |
| sestra | ? |
| matka | ? |
| student | ? |
| město | ? |
| kniha | ? |

<details>
<summary>**Answers**</summary>

| Nominative | → Dative |
|:-----------|:---------|
| bratr | **bratrovi** |
| sestra | **sestře** |
| matka | **matce** |
| student | **studentovi** |
| město | **městu** |
| kniha | **knize** |

</details>
