## Quick Practice: Direct Objects

Put the noun in Accusative:

### Set 1: Masculine Animate

1. Vidím ___ (student) →
2. Znám ___ (učitel) →
3. Mám ___ (pes) →
4. Vidím ___ (muž) →
5. Hledám ___ (doktor) →

<details>
<summary>**Answers**</summary>

1. Vidím **studenta** (hard → -a)
2. Znám **učitele** (soft → -e)
3. Mám **psa** (hard → -a)
4. Vidím **muže** (soft → -e)
5. Hledám **doktora** (hard → -a)

</details>

### Set 2: Feminine

1. Mám ___ (kniha) →
2. Vidím ___ (žena) →
3. Chci ___ (káva) →
4. Znám ___ (Praha) →
5. Hledám ___ (restaurace) →

<details>
<summary>**Answers**</summary>

1. Mám **knihu** (-a → -u)
2. Vidím **ženu** (-a → -u)
3. Chci **kávu** (-a → -u)
4. Znám **Prahu** (-a → -u)
5. Hledám **restauraci** (-e → -i)

</details>

### Set 3: No Change (Inanimate/Neuter)

1. Vidím ___ (stůl) →
2. Mám ___ (auto) →
3. Chci ___ (pivo) →
4. Potřebuji ___ (telefon) →
5. Vidím ___ (město) →

<details>
<summary>**Answers**</summary>

1. Vidím **stůl** (inanimate = no change)
2. Mám **auto** (neuter = no change)
3. Chci **pivo** (neuter = no change)
4. Potřebuji **telefon** (inanimate = no change)
5. Vidím **město** (neuter = no change)

</details>
